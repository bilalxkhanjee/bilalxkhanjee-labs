# bilalxkhanjee-labs

AI-assisted web builds by Muhammad Bilal (Zynter Soft). Plain static HTML/CSS/JS, deployed on Vercel. One site per route.

| Route | Site |
| --- | --- |
| `/kairova-agency/` | Kairova — branding agency landing page (fictional brand) |

`/` currently redirects to `/kairova-agency/` until the index page of all demos is added.

## Run locally

Any static server works, for example `npx serve .` from the repo root.
